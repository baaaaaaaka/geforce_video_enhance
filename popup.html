VSR mode shows YouTube's native video layer. non-VSR mode draws video frames into a canvas inside the same player to bypass Chrome's video overlay/VSR display path.

The native host is still kept for diagnostic scripts that verify the --disable_vp_super_resolution path. The user-facing switch does not open a new Chrome window by default.
