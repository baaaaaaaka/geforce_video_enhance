# Changelog

## 0.1.0 - 2026-04-28

- Initial public release of the Chrome/Edge extension.
- Adds YouTube player controls for the VSR path, non-VSR canvas path, side-by-side comparison, and experimental Smooth Motion overlay.
- Includes a Windows native messaging host and WGC/D3D11 presenter for the Smooth Motion route.
- Adds diagnostic scripts for extension smoke testing, output comparison, and Smooth Motion cadence validation.
- Adds GitHub Actions CI and release packaging.
